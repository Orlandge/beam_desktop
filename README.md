# Beam Designer

Beam Designer is a Tkinter desktop app for educational analysis of a single
simply supported beam or cantilever. It calculates reactions, shear, moment,
elastic deflection, and preliminary bending and deflection checks. Designs can
be saved as JSON, results exported as CSV, and a calculation sheet generated
as PDF.

This is preliminary educational screening, not a code-compliant design or a
substitute for engineering review. Install Python with Tkinter, then install
the required packages:

```bash
pip install numpy matplotlib
```

Start the app from this folder:

```bash
python app.py
```

On systems that use `python3`, run `python3 app.py` instead.
